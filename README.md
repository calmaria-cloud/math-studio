# 数形 · 数学课堂 v0.3

用于 GitHub Pages 的静态发布仓库。函数作图、立体几何、触控数学键盘、分步讲解、撤销重做、本机课程保存与整课文件导入导出。

课程保存在各访问者自己的浏览器中，不上传到服务器。更换站点地址时，请从原地址导出整课，再在新地址导入。

联网打开后等待「离线已就绪」，可安装到主屏幕。`example.math-studio.json` 包含三例题、九步骤，可从「整课」中导入。

本仓库是已验收 v0.3 的网页运行文件，不需要安装依赖或构建。`.nojekyll` 禁用 Jekyll 处理，根目录可直接静态发布。项目域名使用相对资源路径，Service Worker 只控制本项目目录。

包含 Three.js 0.180.0，其许可声明保留在 index.html 中。大陆访问情况取决于实际网络，不能保证各地区、各运营商均可达。
